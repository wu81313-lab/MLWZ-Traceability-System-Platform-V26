# 日志管理模块功能说明

## 模块定位

日志管理模块位于“产品追溯系统 > 系统管理 > 日志管理”下，用于集中记录平台关键操作行为，形成可查询、可追溯、可辅助排障的操作审计记录。模块主要面向平台管理员、运维人员、生产管理人员和数据排查人员，帮助快速定位用户操作、业务状态变化、设备异常、数据上传失败和追溯码关联错误等问题。

## 核心功能

日志管理模块记录平台内关键业务操作，包括用户登录、用户退出、工单创建、工单修改、工单关闭、追溯码关联、追溯码作废、追溯码置换、设备状态变更、数据备份、数据还原等操作。

每条日志记录保留操作人、用户账号、操作时间、操作类型、操作内容、执行结果、关联对象、异常线索等信息。对于失败或异常日志，模块进一步展示失败原因、处理建议、来源终端、IP 地址和请求摘要，便于定位问题来源和后续处理责任。

## 记录范围

模块覆盖以下关键操作类型：

1. 用户登录 / 退出：记录用户进入或退出平台的行为，辅助审计账号使用情况。
2. 工单创建 / 修改 / 关闭：记录生产工单生命周期中的关键变更，便于追踪工单操作责任。
3. 追溯码关联 / 作废 / 置换：记录包装关联、异常码处理、换码操作等关键追溯行为，保障码关系可追溯。
4. 设备状态变更：记录读码器、工控机、PDA 等设备状态变化，例如读码器离线、心跳超时等。
5. 数据备份 / 还原：记录系统维护类操作，便于核对数据恢复、备份范围和执行结果。
6. 异常问题排查：记录数据上传失败、关联错误、设备离线等问题线索，帮助快速定位异常原因。

## 日志字段

日志列表主要展示以下字段：

- 日志编号：唯一标识一条操作日志。
- 操作时间：记录操作发生的具体时间。
- 操作类型：标识操作动作，例如工单创建、追溯码作废、设备状态变更。
- 用户账号：执行操作的登录账号或系统任务账号。
- 操作人：执行操作的人员名称或系统任务名称。
- 操作内容：描述本次操作的具体业务内容。
- 执行结果：标识操作结果，包括成功、失败、异常。
- 关联对象：展示本次操作关联的工单、追溯码、设备、备份文件等对象。
- 异常线索：展示失败或异常相关的排查提示。

日志详情补充展示：

- 业务模块
- 来源终端
- IP 地址
- 失败原因
- 处理建议
- 请求摘要

## 查询能力

模块支持按以下条件筛选查询：

1. 操作时间：支持按日期范围筛选日志，便于按问题发生时间定位记录。
2. 操作类型：支持按具体动作筛选，例如用户登录、工单创建、追溯码关联、设备状态变更、数据还原等。
3. 用户账号：支持按账号或操作人姓名模糊查询，便于定位某个用户的操作记录。

查询结果支持分页展示，并可导出为本地 CSV 文件，方便线下归档、审计和问题复盘。

## 异常排查价值

日志管理模块可辅助定位以下典型问题：

1. 数据上传失败：通过来源终端、失败原因、异常线索和处理建议，判断是否由 PDA 离线、网络超时、工控机同步队列积压等原因导致。
2. 追溯码关联错误：通过关联对象、请求摘要和失败原因，复核父子码层级、包装关系配置和重复关联情况。
3. 设备离线异常：通过设备状态变更日志查看读码器离线时间、最近心跳、设备 IP 和建议检查项。
4. 工单操作追溯：通过工单创建、修改、关闭日志，确认工单关键变更的操作人、时间和变更内容。
5. 数据备份还原审计：通过备份、还原日志核对执行人、执行结果、备份文件和还原范围。

## 设计原则

日志管理模块以只读审计为核心，不提供新增、编辑、删除日志能力，避免人为修改审计记录影响可信度。模块通过统一的列表、筛选、详情和导出能力，为平台关键操作提供集中查看入口，并为生产、追溯、设备和数据维护场景提供排查依据。
